
# Mosaic – Visual Discovery

Mosaic is a responsive image discovery application where users will be able to search for topics and explore related images. The application is built using HTML, CSS and JavaScript without any external frameworks. I chose a forest green and warm cream colour palette to create a calm and welcoming visual experience. I included category suggestion chips to help users explore common topics and an empty-state message to guide first-time visitors. The results section uses CSS Grid to adapt to different screen sizes.
